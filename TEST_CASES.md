## ⚙️ Правила взаимодействия с задачами

### Кнопка "More" (⋮)

При выполнении операций с существующими задачами (редактирование, удаление, дублирование и т.д.), необходимо:

1. **Найти задачу** в списке
2. **Нажать на кнопку "More"** (три точки вертикально ⋮ - MoreVertIcon)
3. **Выбрать нужную операцию** из выпадающего меню

Доступные операции в меню:

- ✏️ **Edit** - редактирование задачи
- 🗑️ **Delete** - удаление задачи
- 📋 **Duplicate** - дублирование задачи (если доступно)
- 📌 **Pin** - закрепление задачи (если доступно)

### TC-001: Создание новой задачи

| **Приоритет** | 🔴 Критический |
| ---------------------- | --------------------------------- |
| **Категория** | Управление задачами |
| **Описание**   | Базовый тест для создания новой задачи со всеми полями (название, описание, категория, цвет, дедлайн). Этот тест является основой для других тестов, так как при редактировании, удалении и других манипуляциях требуется созданная задача |
| **Предусловия** | Приложение загружено и доступно; localStorage очищен |

| № | Шаг | Ожидаемый результат |
|---|---|---|

| 7 | Нажать "Save" | Задача появляется в списке задач со всеми данными |

### TC-006: Валидация максимальной длины названия задачи (256 символов)

| **Приоритет** | 🔴 Критический |

| **Категория** | Валидация входных данных |
| **Описание**   | Система должна ограничить длину названия задачи максимум 256 символами. Это предотвращает переполнение хранилища и обеспечивает корректное отображение в интерфейсе. При попытке ввести символы сверх лимита они не должны вводиться |
| **Предусловия** | Приложение загружено; форма создания задачи открыта |

| № | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Открыть форму создания задачи | Форма загружена |
| 2 | Попытаться ввести 300 символов в поле названия | Символы вводятся в поле |
| 3 | — | Введено не более 256 символов (остальные не вводятся или обрезаны) |

## 📝 Примечания

- **URL приложения**: https://react-cool-todo-app.netlify.app/
- **Очистка**: Перед каждым тестом рекомендуется очищать localStorage
- **Инструмент**: Тесты используют Playwright для автоматизации
- **Релиз**: Критические тесты должны быть выполнены перед каждым релизом
- **Меню действий**: При редактировании, удалении и других манипуляциях с задачами необходимо:
  1. Нажать на кнопку **"More" (⋮ три точки вертикально)** на задаче
  2. Из выпадающего меню выбрать нужную опцию (Edit, Delete, и т.д.)

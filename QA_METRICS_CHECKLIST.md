## ✅ Чек-лист функциональности

### Основной функционал (MUST HAVE)

- [ ] **Создание задач**
  - [ ] Пользователь может добавить новую задачу
  - [ ] Название обязательно (валидация)
  - [ ] Максимум 256 символов
  - [ ] Описание опционально (до 2048 символов)
  - [ ] Можно выбрать категорию
  - [ ] Можно выбрать дату выполнения
  - [ ] Задача появляется в списке сразу

- [ ] **Редактирование задач**
  - [ ] Пользователь может отредактировать название
  - [ ] Пользователь может отредактировать описание
  - [ ] Можно изменить категорию
  - [ ] Можно изменить дату
  - [ ] Изменения сохраняются

- [ ] **Удаление задач**
  - [ ] Пользователь может удалить задачу
  - [ ] Требуется подтверждение (попередача)
  - [ ] Задача удаляется из списка
  - [ ] Нет возможности восстановления

- [ ] **Отмечание выполненности**
  - [ ] Пользователь может отметить как выполненную (чекбокс)
  - [ ] Выполненная задача отображается с зачёркиванием
  - [ ] Можно снять отметку
  - [ ] Статус сохраняется

- [ ] **Сохранение данных**
  - [ ] Все задачи сохраняются в localStorage
  - [ ] При перезагрузке данные восстанавливаются
  - [ ] Нет потери данных при закрытии браузера
  - [ ] Синхронизация с IndexedDB если есть

### Фильтры и поиск (SHOULD HAVE)

- [ ] **Категории**
  - [ ] Все задачи видны по умолчанию
  - [ ] Можно фильтровать по категории
  - [ ] Категории создаются/удаляются
  - [ ] Каждой категории можно назначить цвет

- [ ] **Поиск**
  - [ ] Поиск ищет в названии задач
  - [ ] Поиск ищет в описании
  - [ ] Поиск работает в реальном времени
  - [ ] Очистка поиска показывает все задачи

- [ ] **Фильтры**
  - [ ] Фильтр "Выполненные"
  - [ ] Фильтр "Невыполненные"
  - [ ] Комбинированные фильтры работают
  - [ ] Сортировка по дате, алфавиту

### Синхронизация (HIGH PRIORITY)

- [ ] **WebRTC P2P Sync**
  - [ ] QR-код генерируется для синхронизации
  - [ ] Можно отсканировать QR-код (требует камера)
  - [ ] WebRTC соединение устанавливается
  - [ ] Данные передаются без облака
  - [ ] Конфликты задач разрешаются
  - [ ] Оба устройства получают обновления

- [ ] **Импорт/Экспорт**
  - [ ] Можно экспортировать все задачи в JSON
  - [ ] JSON содержит полные данные
  - [ ] Можно импортировать JSON обратно
  - [ ] Валидация JSON при импорте
  - [ ] Дублирование предотвращается
  - [ ] Форматирование сохраняется

### Персонализация (SHOULD HAVE)

- [ ] **Темы**
  - [ ] Темная тема доступна
  - [ ] Светлая тема доступна
  - [ ] Переключение без перезагрузки
  - [ ] Выбор сохраняется
  - [ ] Уважается системная тема

- [ ] **Цветовые схемы**
  - [ ] Несколько цветовых схем
  - [ ] Пользователь может выбрать схему
  - [ ] Цвета применяются ко всему UI
  - [ ] Контрастность приемлема

- [ ] **Настройки**
  - [ ] Уменьшение анимаций
  - [ ] Громкость для синтеза речи
  - [ ] Стиль эмодзи
  - [ ] Язык (если есть)

### PWA функциональность (NICE TO HAVE)

- [ ] **Установка**
  - [ ] Приложение можно установить
  - [ ] Иконка отображается на рабочем столе
  - [ ] Работает как нативное приложение

- [ ] **Offline режим**
  - [ ] Service Worker регистрируется
  - [ ] Приложение работает без интернета
  - [ ] Кэширование работает
  - [ ] При подключении синхронизируется

- [ ] **Manifest**
  - [ ] Manifest.json валиден
  - [ ] Иконки оптимизированы
  - [ ] Splash screen работает

### Общий доступ (HIGH PRIORITY)

- [ ] **Ссылка для общего доступа**
  - [ ] Можно получить ссылку на задачу
  - [ ] Ссылка содержит данные
  - [ ] По ссылке открывается правильный контент
  - [ ] Безопасное кодирование URL

- [ ] **QR-код для общего доступа**
  - [ ] QR-код генерируется
  - [ ] QR-код сканируется
  - [ ] По QR коду открывается ссылка

## 🔍 Тестовые сценарии

### Happy Path (Счастливый путь)

#### Сценарий 1: Полный цикл жизни задачи

1. ✅ Пользователь открывает приложение
2. ✅ Видит список задач (может быть пуст)
3. ✅ Нажимает кнопку "Добавить"
4. ✅ Заполняет форму: название, описание, категория
5. ✅ Нажимает "Сохранить"
6. ✅ Задача появляется в списке
7. ✅ Пользователь отмечает её как выполненную
8. ✅ Видит что задача зачёркнута
9. ✅ Нажимает на задачу для редактирования
10. ✅ Изменяет название и описание
11. ✅ Сохраняет изменения
12. ✅ Возвращается в список
13. ✅ Видит обновленную задачу
14. ✅ Удаляет задачу
15. ✅ Подтверждает удаление
16. ✅ Задача исчезает из списка
17. ✅ Перезагружает страницу
18. ✅ Задача не восстанавливается (удалена)

### Negative Scenarios (Негативные сценарии)

#### Сценарий 2: Валидация формы

- [ ] Пользователь пытается создать задачу без названия
  - ❌ Система показывает ошибку
  - ❌ Задача не создаётся

- [ ] Пользователь вводит название из 300 символов
  - ❌ Система обрезает до 256
  - ❌ Предупреждение показывается

- [ ] Пользователь вводит спецсимволы `<script>`
  - ❌ Скрипт не выполняется (XSS защита)
  - ✅ Текст экранируется и отображается

#### Сценарий 3: Потеря интернета

- [ ] Пользователь создал задачу online
- [ ] Соединение разорвано (offline)
- [ ] Пользователь создаёт ещё одну задачу offline
- [ ] Данные сохраняются локально
- [ ] Интернет восстанавливается
- [ ] Обе задачи видны
- [ ] Нет потери данных

### Edge Cases (Граничные случаи)

- [ ] Очень длинное название (256+ символов)
- [ ] Очень длинное описание (2048+ символов)
- [ ] Спецсимволы в названии: `!@#$%^&*()`
- [ ] Unicode символы: `你好世界 🌍 Привет`
- [ ] Быстрое добавление/удаление 100 задач
- [ ] Задача с пустым названием
- [ ] Задача с только пробелами
- [ ] Две задачи с одинаковым названием
- [ ] Создание после очистки хранилища
- [ ] Экспорт 1000+ задач

## 🔐 Безопасность

- [ ] **XSS (Cross-Site Scripting)**
  - [ ] `<script>alert('xss')</script>` - не выполняется
  - [ ] HTML теги экранируются
  - [ ] JavaScript в атрибутах не выполняется

- [ ] **CSRF (Cross-Site Request Forgery)**
  - [ ] Локальное приложение, CSRF не применимо
  - [ ] Но проверить что нет внешних запросов

- [ ] **LocalStorage безопасность**
  - [ ] Чувствительные данные не хранятся plain-text
  - [ ] Нет API ключей в хранилище
  - [ ] JSON структура валидна

- [ ] **URL безопасность**
  - [ ] Share ссылки безопасно кодируют данные
  - [ ] Нет раскрытия внутренней структуры
  - [ ] Base64 кодирование работает
